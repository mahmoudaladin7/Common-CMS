# Writing and publishing a blog post

1. Sign in and choose the correct website. Open **Blog posts**, then **Write a blog post**.
2. In **Write your story**, enter a title, a short introduction, an optional cover image and the story itself. Changes are saved automatically as private drafts. Wait for the saved indicator before leaving the editor.
3. Use the **Locale** selector to write English and Arabic content. The account Language setting changes the interface; it does not translate your text automatically.
4. In **Post details**, check the public author name and category. The publication date is filled on first publication; entering a future date does not schedule publishing.
5. **Search & sharing** contains optional search title, description and social image settings.
6. Use **Preview** to review the saved draft on the website. Drafts require a signed-in account with permission for that website.
7. Choose **Publish changes** when ready. The public website then reads the published post. Additional edits autosave privately until you publish those changes too.
8. Keep the **URL address** stable after sharing it. To remove a post from public view, use the unpublish control. Earlier versions remain in version history.

Editors and Website Admins can write and publish. Viewers can review and preview but cannot change content. Only Website Admins and Super Admins can delete content. Ask a Super Admin to assign another website or change account permissions.
